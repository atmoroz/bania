План: PWA-приложение для бани
Стек
Next.js (App Router) + TypeScript: публичный сайт и админка в одном приложении.
Tailwind CSS + shadcn/ui: вёрстка и UI-компоненты.
Supabase:
PostgreSQL — база данных;
Auth — вход для админа;
Storage — фото галереи и фоны;
Realtime — календарь занятости обновляется у всех сразу.
PWA через Serwist (преемник next-pwa): установка на телефон, офлайн-кэш.
Календарь: FullCalendar или react-day-picker плюс свои слоты по часам.
Уведомления владельцу: Telegram-бот о новой брони.
Деплой: Vercel и свой домен.
Альтернатива для админки: Payload CMS (встраивается в Next.js) — для контента; брони всё равно хранить в своей таблице.
Структура БД (минимум)
Таблица Поля / назначение
bookings дата/время начала и конца, имя, телефон, статус (ожидает / подтверждено / отменено). Двойную бронь блокирует exclusion constraint по tstzrange.
prices услуги, тарифы, порядок
gallery URL фото, подпись, порядок
reviews имя, текст, оценка, флаг одобрения (модерация)
settings фон, тексты главной, контакты, соцсети
Страницы
Главная: фон, описание, кнопка «Забронировать».
Календарь: свободно / занято, форма заявки.
Прайс.
Галерея.
Отзывы: список и форма.
Контакты: карта, телефон.
/admin: брони (подтвердить / отменить), прайс, галерея (загрузка), фон и тексты, модерация отзывов.
Этапы
Дизайн и контент: структура страниц, фото, прайс.
Публичный сайт: главная, прайс, галерея, отзывы, контакты.
Календарь и бронь: показ свободного и занятого времени, форма заявки, уведомление в Telegram.
Админка: управление бронями и всем контентом.
PWA и запуск: манифест, иконки, SEO, домен.
